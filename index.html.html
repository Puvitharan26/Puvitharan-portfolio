Final Year Project · IT

SmartQuote — Quotation Analytics System

Universiti Kebangsaan Malaysia

A web-based quotation analytics system that automates OCR-based extraction of financial data from PDF and scanned quotation documents, with a Human-in-the-Loop validation workflow.

  • 85–95% extraction accuracy via a custom two-pass algorithm & three parsers.
  • 100% accuracy on verified records through HITL review before DB submission.
  • Real-time analytics dashboard with 8 visualisation components & 28+ SQL trends.
  • Rule-based recommendation engine (R1–R5) for win rates, margins & pricing.
  • RBAC, bcrypt, prepared statements, audit logging — 56/56 functional, 15/15 UAT, 12/12 OWASP tests passed.
